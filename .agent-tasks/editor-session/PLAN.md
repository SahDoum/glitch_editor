# Сессия редактора, переиспользование расчётов и жесты

Источник: `docs/REFACTOR.md`, обновлённая ветка `e497517`.

## Цель
Единый путь Preview/Apply/Auto Apply с идентичностью плана и ограниченным кэшем/присоединением; ноль кодирований при перестановке выключенных записей. Один владелец отмены до decode/publication; единые переходы сессии и инструментов/жестов; атомарные валидные настройки. Привязать Scan stages к документу/плану, Reset→Save и снимок до await; immutable Scan draft. Общий preview URL/decode и progressive single-flight. Кэш проекции маски и упрощение DCT UI. Координировать API других агентов.

## Зона ответственности
src/App.tsx (единственный владелец); src/application/preview-coordinator.ts; src/application/coefficient-effect-settings.ts; src/application/jpeg-result.ts; src/ui/**; src/features/**

## Шаги
1. Прочитать AGENTS.md, PRODUCT.md, docs/ARCHITECTURE.md, релевантные спецификации и существующий код.
2. Воспроизвести оставшиеся проблемы тестами, отметить уже реализованные пункты.
3. Согласовать внутренние API с соседними агентами; менять только свою зону.
4. Реализовать небольшими проверяемыми изменениями без новых зависимостей.
5. Запустить целевые тесты, typecheck и lint; отчитаться координатору с файлами, командами, результатами и ограничениями.

## Критерии приёмки
Регрессии реального пути на stale decode, смену файла/Reset, одинаковый Preview→Apply, disabled reorder, tool/keyboard parity, invalid settings, Reset→Save и повторный export. Сохранить интерфейс и оригинальные байты.

Оригинальные байты JPEG неизменны; текущие инструменты, режимы экспорта и Undo/Redo сохранены. Изменения внутренних контрактов, прямо предусмотренные REFACTOR.md, входят в запрос пользователя; новые зависимости/поддержку JPEG не расширять.
