# Рефакторинг инструментов холста

Рабочая ветка — `refactor-interfaces-architecture`. Выполнить [план рефакторинга холста](../../docs/canvas-tools-refactoring-plan.md) из коммита `d704841`.

Перед правками прочитай [правила репозитория](../../AGENTS.md), [спецификацию продукта](../../PRODUCT.md) и [архитектуру](../../docs/ARCHITECTURE.md). Сверь текущие обработчики, тесты и исходное состояние ветки с планом. Файлы редактируй в общей рабочей копии. Изменения для проверки остаются в рабочем дереве.

## Порядок работы

1. **Восстанови исходную проверку ветки.** Убери отдельный ID `engraving-vertical` и устаревшие ожидания. Проверь оба направления через один эффект Engraving и воспроизведение вертикальной операции. Прогони `npm run check` и сообщи исходные сбои отдельно от результатов правки.
2. **Вынеси Select и All из `App.tsx`.** Подключи их к реестру инструментов. Один адаптер выбирает владельца сессии при нажатии и ведёт жест до отпускания или отмены. Подключи клавиатурное выделение, панорамирование и существующие жесты эффектов. Кнопки и хоткеи используют общий путь выбора инструмента. Готовая маска проходит через общую точку завершения.
3. **Доведи Transfer и Repeat.** Подключи подсказки по фазам, сброс кнопкой и клавишей R, очистку черновика при отмене и смене компонента. У Transfer допустимое отпускание добавляет один шаг. У Repeat шаг добавляется по Apply. Сверь контуры с геометрией операции.
4. **Перенеси Brush и контекстные контролы.** Сохрани привязку, интерполяцию точек, ограничение длины и автоприменение после завершения. Отдельно проверь мазок, который вышел за край и вернулся. Оцени, как разрывы проходят валидацию маски, восстановление, Preview, Apply и сохранение проекта. Если для исправления потребуется менять совместимость `.jpglitch` со старыми сборками, пришли координатору конкретную развилку из основного плана и продолжай независимые правки холста.
5. **Заверши интеграцию и проверку.** Убери дубли обработчиков, обнови архитектурное описание, прогони регрессии и `npm run check`. Проверь основные жесты в браузере на JPEG из `tests/fixtures/` и укажи, какие сценарии реально прошёл.

## Приёмка

- Зарегистрированные инструменты выбираются кнопкой и хоткеем. Ввод текста сохраняет обычное клавиатурное поведение.
- Сессия принадлежит одному указателю. Отпускание завершает жест один раз. Отмена, потеря захвата и смена контекста очищают черновик. Панорамирование сохраняет рабочую маску и историю.
- Select работает указателем и клавиатурой с существующей привязкой и преобразованием EXIF. All создаёт полноразмерную область. Автоприменение срабатывает только для завершённого жеста, которому оно разрешено.
- Transfer и Repeat показывают подсказку по текущей фазе, контур совпадает с фактическим назначением. Для кисти проверяются границы кадра, ограничение точек и ошибка применения.

## Отчётность

После каждого этапа пришли координатору сообщение с изменёнными модулями, выполненными проверками и препятствиями. Важные решения и результаты можно записывать в отдельные Markdown-файлы в этой папке. Правки `STATUS.md` ведёт координатор.
