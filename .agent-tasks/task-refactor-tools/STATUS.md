## Интерфейс инструментов

All, Brush и Select реализуют [`CanvasInteraction`](../../src/features/canvas-tools/types.ts). Transfer и Repeat подключены через `EffectCanvasInteraction`, панорамирование через `CanvasPan`. `CanvasPointer` открывает сессии через общий `begin`. Холст получает подсказки и контуры от активного контроллера. Реестр создаёт экземпляры для редактора и предоставляет View, включая контрол размера кисти.

- Устаревший ID отсутствует в `src` и `tests`. Тест покрывает оба направления Engraving и воспроизведение вертикальной операции из истории.
- Итоговые `npm run check` и `git diff --check` прошли. 321 тест прошёл, 1 пропущен (нужен внешний JPEG-декодер).
- Тест с дополнительным классом из реестра проверяет активацию, подсказку и жизненный цикл указателя. Результат жеста эффекта публикуется с ID эффекта-владельца.
- Готовые точки разорванного мазка хранятся в одной форме. Покрытие сохраняет зазор, Restore Selection копирует все точки, `.jpglitch` сохраняется и читается в действующем формате.
- Повторный прогон в Chromium на финальном коде подтвердил выбор инструментов с клавиатуры, Auto Apply, панорамирование по пробелу и средней кнопкой, смену подсказок Transfer, отмену при потере захвата и смене Copy/Swap, Undo/Redo, сброс по R, ручной Apply в Repeat и применение разорванного мазка.
