# WASM, измерения повторного использования и проверки сборки

Источник: `docs/REFACTOR.md`, обновлённая ветка `e497517`.

## Цель
Освобождать временный вход WASM сразу после open, общий versioned JS/WASM loader с проверкой ABI. Прототип/измерения Worker на срок документа и одной checkpoint: отдельно reuse WASM, оценка codec lifecycle после encode, память и parity; включать production путь только при доказанной корректности. Оценить DCT constants/затронутые блоки с сохранением RNG. Smoke собранного Worker с base path и Block Transfer. Независимый decoder: явный skip при отсутствии, failure при ошибке настроенного; убрать дубли typecheck/maxWorkers и неиспользуемый logger после проверки.

## Зона ответственности
src/jpeg/coefficient.worker.ts; src/jpeg/codec/**; общий codec loader (согласовать scan-engine); scripts/**; package.json; vite.config.ts; .github/workflows/ci.yml; codec/progressive/smoke tests

## Шаги
1. Прочитать AGENTS.md, PRODUCT.md, docs/ARCHITECTURE.md, релевантные спецификации и существующий код.

4. Реализовать небольшими проверяемыми изменениями без новых зависимостей.
5. Запустить целевые тесты, typecheck и lint; отчитаться координатору с файлами, командами, результатами и ограничениями.

## Критерии приёмки
Побайтовое/коэффициентное совпадение baseline/progressive на фикстурах; smoke действительно проходит собранный Worker и base path; измерения времени/памяти и вывод о checkpoint записаны; build/check без повторного typecheck.

Оригинальные байты JPEG неизменны; текущие инструменты, режимы экспорта и Undo/Redo сохранены. Изменения внутренних контрактов, прямо предусмотренные REFACTOR.md, входят в запрос пользователя; новые зависимости/поддержку JPEG не расширять.
