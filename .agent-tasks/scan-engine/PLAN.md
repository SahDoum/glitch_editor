# Scan Corrupt: безопасный транспорт и один рабочий буфер

Источник: `docs/REFACTOR.md`, обновлённая ветка `e497517`.

## Цель
Проверять envelope/Result до .ok и корректно завершать malformed Worker responses. Один рабочий буфер для N стадий и повторное использование проверенной структуры; N+1 разборов, сохранение структурной проверки после каждой стадии, transferable результата. Кодек loader согласовать с codec-performance; App не менять.

## Зона ответственности
src/application/scan-corruption.ts; src/jpeg/scan-corruption.ts; src/jpeg/scan-corruption.worker.ts; соответствующие тесты

## Шаги
1. Прочитать AGENTS.md, PRODUCT.md, docs/ARCHITECTURE.md, релевантные спецификации и существующий код.
2. Воспроизвести оставшиеся проблемы тестами, отметить уже реализованные пункты.
3. Согласовать внутренние API с соседними агентами; менять только свою зону.
4. Реализовать небольшими проверяемыми изменениями без новых зависимостей.
5. Запустить целевые тесты, typecheck и lint; отчитаться координатору с файлами, командами, результатами и ограничениями.

## Критерии приёмки
Сравнить точные байты/отчёты 1–8 стадий с прежним алгоритмом, отказ посередине, immutable original; malformed response, отмена и очистка Worker проверены.

Оригинальные байты JPEG неизменны; текущие инструменты, режимы экспорта и Undo/Redo сохранены. Изменения внутренних контрактов, прямо предусмотренные REFACTOR.md, входят в запрос пользователя; новые зависимости/поддержку JPEG не расширять.
